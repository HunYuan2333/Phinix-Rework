# T5 本地主题包手工操作步骤

日期：2026-10-11。代码与同批制品用于后续游戏验收；本批未运行以下场景或故障注入。

## 准备

使用同批客户端构建 Output/phinix-rework，避免只替换 Store DLL 而遗漏 Utils、Host 或 abstractions。本地候选在 Phinix/local-theme-packages/2026-10-11-t5-local；此前 t5 首批示例 ZIP 的产品版本范围不适用于当前客户端，请用本批包。

## 正常闭环

1. 关闭 DevMode，打开商店的“本地主题包”，选择 local-demo-1.0.0.zip。确认显示名称/作者/版本、本地未审核来源，点击安装。
2. 点击主题选择器，选择包的 Ocean/海蓝主题，观察聊天正文/输入及按钮配色。应用无需重启。
3. 调整正文颜色，应用；关闭再打开保有覆盖。点导出，在弹窗填写自己的作者/名称，保留生成的新包 ID，选择 ZIP 路径。
4. 确认文件存在，成功提示给出完整路径，复制路径可用。文件管理器打不开仍可找到 ZIP；重复相同路径应拒绝覆盖。
5. 从商店安装刚导出的 ZIP，选择 main 变体；修改并再次导出时复用自己的包 ID、增加版本、换输出路径，再从商店更新。
6. 安装 local-demo-1.1.0.zip 更新演示包：同 ID 的 Ocean 保留选择和 profile，新文件立即生效；已删除的 Ember 变体若被选中则默认显示并保留原选择意图。
7. 显式卸载当前所选主题所属包，确认后选择持久改为默认；重启保持默认。其他包和用户覆盖保留。

## 拒绝与恢复关注项

- 重复摘要/降级拒绝；同版本不同摘要只允许本地修订。主题 ID 与 DLL 包 ID 冲突应拒绝，不能换 kind 绕过。
- 预览后已安装摘要变化，旧确认不能覆盖新状态；失败候选不能沿用上一次成功候选。
- 额外文件/DLL、错误摘要/长度/宿主范围、链接/路径别名/未知文件不得被安装或自动删除。
- 意外丢失/损坏只回退显示、保留选择意图；已有用户 Themes XML 不被删除或受管接管。
- preparing 日志恢复回滚已验证暂存；committing 决定后恢复完成提交。卸载设置写失败保留 journal 后处理，下一次刷新/启动继续；用户后续保存的选择不被旧意图覆盖。

恢复检查涉及磁盘故障/异常中断，源码实现不等同这些场景已验证。不要求为三端文件管理器验收等待；本轮重点是本地操作与状态语义。线上投稿、上架和快捷上传整体延期。
