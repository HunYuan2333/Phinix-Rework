# T3 统一游戏验收

先退出游戏，整包同步 Output/phinix-rework，再重启。主题应用仍热更新，维护插件继续用原 1.1.1 单包。本批只完成编译与源码检查，以下游戏步骤未执行。

## 覆盖与准备

| 页面/控件 | 本次关注 |
| --- | --- |
| Host 主窗口、侧栏与抽屉 | Tab/溢出、按钮、背景、接受键、原选择 |
| 连接/登录与 Mod 设置 | 输入/焦点、禁用、设置提示、原状态 |
| 扩展模块/包管理 | 状态与日志热更新、禁用规则、滚动 |
| 聊天、用户名、通知 | 正文、输入、昵称参数、无颜色文本缓存 |
| 交易列表和窗口 | 选择/数量、角色、当前报价页/已接受状态 |
| 库存/交付选择与设置 | 背景、单选、输入、原状态 |
| 商店主视图/辅助窗口 | 按钮、搜索、Workshop 链接、进度、更新提示 |
| 公共控件 | 正常/悬停/按下/禁用、焦点、占位、滑块、进度 |

可以把 local-theme-samples/2026-10-11/07-controls-t3.xml 放到之前的用户主题目录，再刷新选择；该文件明显区分按钮、焦点和背景。继续使用测试 02 的聊天颜色和测试 03 的库存颜色，对比前几批样例；旧样例缺少新控件键时应使用角色回退/注册默认值。

这里只检查 Phinix 的可主题化样式。游戏原生窗口边框、滚动条/Tab/输入/复选/单选/滑块纹理、通用菜单和确认框、物品/图片素材保持原实现；输入背景是染色，不是完全替换纹理。不要只替换 SDK 或一个 DLL，需整包同步。

## 公共控件

- 在主题窗口调整按钮背景、悬停/按下、输入焦点边框：应用后主题窗口、库存、商店主视图和扩展管理应更新。
- 主题搜索空值时显示占位提示；聚焦后隐藏提示。输入数值过程中切换配色项，原未完成输入保留。禁用的应用按钮不能触发操作。
- 选择昵称饱和度/亮度，用滑块调整：数值框同步，点击应用前聊天颜色不变，应用后更新。切换主题保留草稿，关闭窗口丢弃未应用内容；窄窗口保留数值框输入。

## 聊天与通知

- 使用已有测试 02 改聊天正文/输入框颜色，确认已存在消息更新，用户自定义富文本与提及高亮仍保留。
- 在聊天框输入一段未发送内容，切换主题后内容仍在；检查回车发送、回复关闭与之前一致。不需要为验收向别人发送消息。
- 用户侧栏在线人数和通知相对时间在主题应用后直接变色，无需等待人数/时间变化；通知正文与关闭按钮仍可用。
- 调整昵称 HSV 参数，普通他人名字随参数更新，自己的名字与合法自定义富文本仍按原规则显示。用户名和正文列表的选择/滚动位置不因配色被主动重置。
- 聊天和交易设置的复选框/输入消费公共角色；检查主题变更不会自行勾选设置。

## 交易

- 有现存交易时打开窗口：搜索、数量输入与按钮应更新；已接受标记、当前报价页、取消强调仍能辨认。
- 数量字段继续限制原可输入字符与最大长度，配色不会改变数量、报价或接受状态。无需为验收刻意提交/取消交易。
- 无交易时可检查列表占位和设置窗口；不存在的真实交易场景应记录为未验证。

## Host、库存与商店

- 打开主窗口、窄窗口侧栏抽屉和 Mod 设置，切主题后文字/背景更新。原 Tab、侧栏选择、输入和滚动不应由配色主动重置。
- 连接设置的有效性与连接中禁用规则保持；登录窗口的输入与提交仍走原行为。可以只检查可见窗口，不需要为配色验收发起连接或登录。
- 扩展模块/包管理的状态、日志、重启提示随配色更新，不能因为切主题更改启用设置。
- 库存列表与数量编辑、交付方式单选消费当前样式；已有物品/计划不变，不需要点击提取、交付或保存计划。
- 商店搜索与按钮更新，禁用操作仍禁用；Workshop 项的链接使用强调色。打开外链仍走原链接服务，不能改变安装行为。
- 若自然出现更新横幅或下载进度，检查主题颜色与关闭操作。没有这些状态可记录未验证，不需要人为制造更新或下载。
- 使用开发者模式时可检查本地 ZIP 选择窗口的路径输入、浏览和窄屏布局；关闭即可，无需真正安装本地包。
