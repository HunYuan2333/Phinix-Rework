# UX2-08 补充切片：主题编辑器易用性

日期：2026-10-18。状态：源码、双版隔离构建和白盒检查完成；游戏验收待测。本记录不代表成品主题选择/商店路径的 UX2-08 全部完成。

## 用户反馈与本轮结果

反馈集中在找不到正在看的区域、名称太专业、设置项多且缺少醒目分类。尤其有人想调大面积背景，却只改到了局部窗口。用户建议以背景、输入框、文字等通俗名称组织，并标记常用项。

- 默认进入“★ 常用配色”，首先选中“主窗口与弹窗背景色”。十项入门设置依次为：主窗口与弹窗背景、右侧面板与通用卡片背景、普通文字、辅助说明文字、输入框背景、普通按钮背景、链接与重点提示、主要按钮、选中标签背景、边框与分隔线。
- 这些设置在完整列表也带“★ 常用”文字标记，不只依赖颜色。这里的“常用”是本轮入门推荐集合，不是使用频率统计结论。
- “全部分类”按注册项的所属模块及分组显示独立粗体标题。第三方插件沿用自己的注册名称、说明和分类；没有官方专属 renderer。超过十个分组时，第十组容纳剩余分类，保留每行的所属信息，不丢项，也不超公共页面 16 section 上限。
- 搜索始终查找全部注册项，支持名称、说明、模块、分组和原始编号。即使从常用视图搜索，也能找到插件设置；无结果可见。切换视图、搜索不清空选中项和未完成的颜色草稿。
- R/G/B/A 改为“红色多少 / 绿色多少 / 蓝色多少 / 不透明度（0 透明，1 不透明）”，四项都有滑块，仍支持原有 0～1 数值输入。无效输入继续阻止应用，不丢失原文；修正后可直接保存。
- 名称增加具体作用范围；列表不再逐行堆技术编号和继承来源，编号保留在所选项的“高级识别信息”中。预览色块使用可读名称。
- 常驻操作聚焦换主题、应用并保存、关闭。刷新、清除全部个人修改、导出及导出后的文件操作进入公共“更多操作”菜单。ZIP 路径由原有导出对话框填写，不再占编辑器首页。
- 中英文文案同步更新。未将访谈中的“skill”等词变成新的玩家操作，也未因聊天中的建议自动发布工坊介绍图。

## 真实作用范围及边界

源码依据：`Client/ClientExtensionAbstractions/UI/ClientWidgets.cs` 的 `ClientThemeWindowDrawing.DoWindowBackground`、`Client/Source/GUI/Windows and panels/ServerTab.cs` 的主窗绘制及侧栏表面、公共 presentation 的背景和色块路径。

`ui.background` 同时用于主窗口底色和多数 Phinix 弹窗，当前不存在独立的主窗/弹窗背景编辑项，因此名称明确写为“主窗口与弹窗背景色”。`ui.surface` 用于右侧面板与通用卡片，消息、交易报价、库存等指定颜色仍由各自项目控制。不是修改一个“背景色”就会覆盖所有区域。透明值仍与底层合成，说明提示提高不透明度可看清大面积底色。

沿用原有 ThemePresentationWindow、公共 presentation section/list/slider/action menu、typed action point 和 catalog；没有第二套主题、动作、确认或自绘编辑器。未修改公开 API、持久化 key、默认颜色、主题 XML 格式、Apply 保存规则、继承规则或插件业务逻辑。修改草稿只更新色块，点击应用后才改变实际界面；这不是实时游戏界面预览。

## 第二轮：内嵌原版调色盘与高级颜色输入

用户试玩第一轮后仍认为操作麻烦，明确要求参考原版落地灯调色界面、内嵌显示，默认用调色盘，给高级用户保留十六进制和 RGB。

### 已实现

- 默认用原版 `Verse.Widgets.HSVColorWheel` 色轮及 `Widgets.ColorBox` 色格，无额外窗口。两种游戏引用均核对存在对应公共接口，双版直接编译调用，未复制灯具窗口或游戏反编译实现。
- 内嵌 60 个通用预设色，含灰阶、不同鲜艳度和明暗的颜色；增加明暗滑块。不复制灯具专用色温、微光、通电或建筑存储规则。
- 宽度足够时色轮与色块并排；窄窗口上下排列，色块自动换行，属于现有编辑区滚动内容。
- 不透明度独立可调。色轮、明暗和预设色只替换 RGB，不擅自改透明度；色轮保持明亮可辨，调整深色时仍保留原来的明暗，纯黑选新色则可正常获得可见颜色。
- “高级调整：十六进制 / RGB”展开后出现十六进制框与原有 RGB 数值/滑块。默认收起，展开状态在本次编辑窗口内保留。
- 十六进制接受有无 `#` 的六位或八位形式，大小写不限，允许首尾空格。六位保留当前不透明度，八位为 RRGGBBAA。保留用户实际输入的原文，不在输入六位时强制扩展成八位，避免妨碍继续输入透明度。
- 色盘、十六进制和 RGB 编辑同一份草稿，修改后相互同步。输入未完成/非法时保留原文、阻止应用；重新选色或输入正确值可直接纠正，不影响其他项目的未完成草稿。
- 当前颜色色块移至所选项固定标题区，不必滚到页面底部才查看。新修改会清除上一次“主题已应用”的旧成功提示。
- 仍需点击“应用并保存”才改变实际界面和持久化，不增加失焦保存或自动应用。

### 通用能力与兼容

在公共 presentation 文本字段中增加中立的 `WithColorPicker(ClientPresentationColorPicker)` 投影，所有消费者都可用。描述符只携带颜色与明暗标签，公共 renderer 负责控件、布局、拖动状态和普通输入队列，owner 负责解析、草稿和保存。不是主题编辑器专用 renderer，也没有第二套动作或颜色存储系统。

色盘字段不能与数字滑块叠加，暂不支持放进紧凑行或消息输入条，合同显式拒绝这些组合。拖动状态按 session/字段保存，重投影时保持，切换所选上下文、撤掉字段或关闭 session 时清除。禁用/过期上下文不产生可接受的修改；原版控件消费鼠标事件后仍能提交本次正确输入。没有每帧创建色轮贴图，预设色一次生成并复用。
