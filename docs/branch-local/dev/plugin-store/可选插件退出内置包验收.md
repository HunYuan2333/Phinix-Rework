# 可选插件退出内置包验收

[English](OptionalPluginsUnbundlingAcceptance.md) · 2026-10-06

用户明确要求现在移除红包与人才的内置发行，取代此前“独立存档验收前保留内置副本”的计划。这不表示缺包保存、购买持久恢复或旧中继安全已经验收通过。

## 本批交付

- 从 `Phinix.sln` 移除两插件的四个 Contracts/Client 项目及配置/嵌套项；源码/项目保留，供独立发行和专项回归。
- 删除四个自有复制到主体的目标及无用打包资源项。单独编译插件、运行引用它们的回归，不会再向主包发布其 DLL/语言资源。
- 主体和商店构建共用 `Client/Packaging/ClientPackageLayout.targets`，自动清理生成输出中的旧 `13`–`16` 平铺 DLL、副文件/PDB、专属资源和退役 XML。不会操作游戏安装目录、玩家设置、存档或托管插件目录。
- 主包检查改为拒绝这些可选产物。实际主包保留八个扩展 DLL：Chat、Trade、Inventory 各自 Contracts/Client，以及 LegacyAdapter Client、PluginStore Client。保留编号和共享依赖。
- 未修改 Host 业务运行逻辑、协议、旧连接或凭据，未上传红包资产。保留既有程序集/模块/类型身份；历史名称中的 `builtin`/`BuiltIn` 不意味着仍内置。玩家已装的托管插件不会被自动替换。

## 验证

实际执行的完整命令见 [English companion](OptionalPluginsUnbundlingAcceptance.md#validation-performed)。主解决方案列出 25 项，无两可选插件。两组真实 MSBuild 清理测试通过：陈旧产物移除，其他插件/共享文件及存档哨兵保留，重复执行幂等，空目录不产生伪包。

主体/服务器/商店完整构建成功，0 错误、4 条既有 protobuf/废弃 API 警告。两插件专项构建 0 警告错误，人才 .NET/Mono 各通过 68 条断言；随后确认没有把可选产物写回主包。

没有 PowerShell，无法原生运行 `.github/scripts/check-artifacts.ps1 -IncludeClient`。使用等价 Python 扫描读取脚本声明的路径，核对 21 个唯一必要客户端/服务器产物、`/,Common,1.6` 加载目录、无退役文件与游戏/Unity/mscorlib DLL。证据 `/tmp/phinix-unbundle-legacy-artifacts-20261006.json`；构建日志 `/tmp/phinix-unbundle-legacy-build-20261006.log`、`/tmp/phinix-unbundle-legacy-focused-build-20261006.log`。最终正式打包在有 PowerShell 的环境再跑原检查。没有宣称真实游戏验收。

## 游戏更新与人测

退出游戏再部署生成的 `Output/phinix-rework`。建议把主 Mod 文件夹换成干净的新输出；仅覆盖不会删掉旧 DLL。更换前保留你手动放入该 Mod 文件夹的第三方扩展，不删除玩家设置、存档或单独的托管目录。

若继续使用覆盖后的旧文件夹，需移除 `Common/Extensions` 中：

- `13-LegacyRedPacketExtension.dll`
- `14-LegacyRedPacketExtension.Client.dll`
- `15-LegacyTalentTradeExtension.dll`
- `16-LegacyTalentTradeExtension.Client.dll`
- 相邻本地化副文件/PDB、`Resources/LegacyRedPacket`、`Resources/LegacyTalentTrade`，以及旧 `Languages/*/Keyed` 下这两个插件的 XML。

没有独立安装时，两个 Tab 消失是预期行为。人才 [Issue #22](https://github.com/HunYuan2333/Phinix-Plugin-Index/issues/22) 已静态通过，等待你本人批准标签；红包还没有发布/入库资产。移除主包不等于自动上架，也不绕过此前凭据发布拒绝。

先用新测试存档：干净主包只出现聊天/交易/库存/商店；独立安装后重启，检查只出现一个对应 Tab，语言/设置正常，再测停用、卸载、重装。保留旧人才存档原始备份。缺包后重存仍有实际持久化风险：包含挂牌、出租人物或待返还数据的存档，重新安装人才后再打开保存。购买意图仍仅在进程内，移除内置包没有补上跨重启恢复。业务人测详见[人才保护验收](人才贸易输入保护与准入验收.md)。
