## 本批实现

- HTTP 响应最多 16 MiB，人物压缩数据 8 MiB，解压/XML 32 MiB；严格 UTF-8，禁止 XML DTD 和外部解析。限制输入大小不等于认证服务或完整执行时间限制。
- 入站队列达到条数/字符预算时保留旧消息并暂停游标，不把服务器页头当成已消费证明。明确拒绝非法编码/超大事件；修复同一 blob 后续分片被误去重，限制 blob 数量、分片数、累计字符、ID 与去重记录。尚未增加 blob 过期回收。
- 发出购买请求前登记本地意图，收货必须匹配挂牌、卖家、买家、saveToken 和同一 Game 实例。延期或队列失败保留首份原文，拒绝替换载荷及不确定交付后重放。真实交付返回成功后才移除购买；通知失败不触发二次交付。
- 超时只显示待确认并保留挂牌/购买，可以接收同一运行中 Game 的匹配迟到响应，不推断远端失败。结构化 `talent.purchase` 日志只包含有限 ID/结果，不包含人物原文。既有程序集、类型、模块、存储身份和旧协议保持。

**仍未解决：** 新购买记录/原文仅保存在进程内，不是持久交易日志；切存档、清理或退出仍可能丢失，不能承诺跨重启恢复。旧 HTTP、未认证消息来源、信任式付款、出站溢出/重试顺序、有限历史保留仍存在；UUID 匹配不是身份认证。真实 GameComponent/Scribe、缺包重存、托管晚加载与人物恢复需要游戏验收，不能凭静态通过移除内置版本或宣称生产安全。
