## 3. 主包、模块、版本与数据身份

主包 About 的实际 `packageId` 为 **`hunyuan2333.phinixrework`**，支持 RimWorld `1.6`，前置 Harmony。证据：[Client/About/About.xml](../../../../Client/About/About.xml)。开发者指南的 `hunyuan.phinixrework` 示例不可直接复制到新包的 About。

| 模块 | 实际 ExtensionId / 必需模块 | 当前主包 DLL 文件 |
| --- | --- | --- |
| Chat | `builtin.chat`；无显式 DependsOn | `08-ChatExtension.dll`、`11-ChatExtension.Client.dll` |
| Inventory | `builtin.inventory`；无显式 DependsOn | `10-InventoryExtension.dll`、`11-InventoryExtension.Client.dll` |
| Trade | `builtin.trade`；`builtin.inventory` | `09-TradeExtension.dll`、`12-TradeExtension.Client.dll` |
| LegacyAdapter | `builtin.legacy-adapter`；无显式 DependsOn | `10-LegacyAdapter.Client.dll` |
| 红包 | `builtin.legacy-redpacket`；`builtin.trade`、`builtin.inventory` | `13-LegacyRedPacketExtension.dll`、`14-LegacyRedPacketExtension.Client.dll` |
| 人才贸易 | `builtin.legacy-talent-trade`；无显式 DependsOn | `15-LegacyTalentTradeExtension.dll`、`16-LegacyTalentTradeExtension.Client.dll` |

上述文件名来自当前构建目标和本地 Output，不是需要新增的全局编号规范。实际程序集 simple name 是不带文件编号的 `ChatExtension`、`TradeExtension`、`InventoryExtension` 等。

源文件声明与本地产物中：PhinixClient / Utils 为 `0.9.7.0`，ClientExtensionAbstractions 为 `1.1.0.0`。本地业务 Contracts/Client DLL 多为 `1.0.0.0`，红包和人才 Contracts 为 `0.0.0.0`。另有 Framework 协议常量 `Version = 2` 和 Inventory 契约常量 `Version = 5`。这些分别是程序集身份或协议/契约语义，**均不自动等于商店包的 SemVer 或已发布主包兼容版本**。兼容信息来源未冻结时应报告未知。

已有数据位置只核对代码，不读取玩家文件：

- Host 向 StorageProvider 传入相对根 `framework-extensions/client`，Provider 构造时 `Path.GetFullPath` 固定其绝对位置，因此不同启动工作目录仍可能改变下次定位。保留所有旧模块路径，本轮不统一迁移。
- 红包在 ExtensionId 下保存 `inventory-send-*.json`；codec 身份 `legacy-redpacket.template`、版本 `1` 必须保留。未知发送结果继续托管，缺 codec 保留原始库存载荷。
- 人才 `TalentTradeGameComponent` 保存 `pendingReturnIds`、`pendingReturnData`、`saveToken`、`lastSeenVersion` 等字段；保持程序集、类型及 Scribe 键。历史存档缺包行为须在正式拆包前实测。
