## 既定收尾

1. 下载与安装进度：当前包、真实已收/总字节、多包累计，阶段为读取目录、解析、下载、验证、提交、完成/待重启。节流状态通知，不按每个缓冲区写日志；迟到回调不得污染新任务，失败或取消不得显示成功。
2. 启动后台更新提示：复用当前正式目录及访问方式，只检查已安装包，离线不阻塞；显示版本与作者 changelog，不自动下载。版本替换另用有归属校验的事务与中断恢复，验证前不开放升级按钮。
3. A3 已批准来源普通版本监控：复用可信检查/发布链，同版本资产不可改写；来源、模块或依赖政策变化停下并报告。客户端更新仍由玩家主动决定。
4. 最终构建与游戏增量验收；正式域名/环境及旧 Worker/存储清点按已有部署计划处理。红包/人才贸易拆分保留专项资源/存档验收，不为“最后收尾”删除前置条件。

这些是现有计划的缺口；已通过的安装/卸载和标签发布不从头重做。每批记录具体测试及人工测试点，未实施项不写成已完成。

## AI 作者工作流目标

用户有可访问 GitHub 的代理，在 DeepSeek 等 harness 或 Codex 中描述简单需求，助手完成能力检查、建项目、实现、编译、测试、打包、创建/更新作者仓库、发布固定 Release、提交官方索引申请并回报状态。无需预先装 Git 或 gh，且不把某一 harness 作为架构依赖。

### 分层交付

- 跨 harness 的仓库 AGENTS.md：目录和契约入口、主线程规则、生命周期、局部设置/按存档数据区别、语言文件、合法引用与打包、验证、发布范围及失败处理。尽量短，细节链接到稳定指南。
- 可选 skill：按“写插件/测试插件/发布插件”触发，引用通用说明和相同工具；Codex/其他 harness 可各有薄适配。不要求用户把所有技术术语写进许愿。
- 可测试的工具：环境检测、模板生成、构建/打包、发布预检、发布与申请；结构化参数/结果，固定版本，可重入。skill 不直接堆叠临时 shell 命令。
- 人类指南：首次登录、代理、引用路径及失败排查。首次初始化后，已授权的重复发布可自动完成。

### 干净机器与缺失工具

检测操作系统、Python/可用运行时、.NET SDK、RimWorld 1.6 本地引用、网络、Git、gh 和已有授权。列出缺失条件，不假设 PATH 上必有工具。Git/gh 可选；无 Git 使用下载固定源码和 GitHub API 上传源文件/创建提交，无 gh 使用同一 API 创建仓库、Release、资产和 Issue。不能把文件压缩包当成源码版本证据；API 路线也须记录固定源码 commit/tag 和准确资产身份。

没有构建 SDK 或没有用户合法提供的游戏引用时，停在可审阅源码/安装指引，不伪称编译和游戏验收成功，不从第三方下载游戏 DLL。工具自动安装须依据用户授权范围，仅安装必要工具，记录可回退位置，不改全局环境或盲目 sudo。依赖获取失败可恢复，不能生成半成品发布。

### 代理与登录

支持不使用代理、系统/环境代理、显式 HTTP(S)/SOCKS 代理；先检查 GitHub API/源码/Release 下载和构建依赖通道，分类报告 DNS、连接、TLS、403/429 等问题。直接与代理对比须由配置驱动；不要求先开 TUN，不擅自关闭用户代理，也不把所有 403 判为代理故障。

共享同一网络配置，Git、gh、API 后端和 SDK 下载不各自猜设置。代理凭据与 token 使用安全凭据存储或隐藏输入，禁止聊天粘贴、命令参数明文、版本库、输出工件和诊断日志；报告只保留端点类别及错误原因。利用已存在登录；缺失时引导官方网页登录/设备授权或最小权限凭据，明确需要的仓库权限。初始登录属于必要人工步骤，不能承诺无授权自动进入用户账户。

### 发布与审核边界

用户授权的作者仓库源码与 Release 发布可以全自动：固定源码 → 从该源码构建 → 静态/内容检查 → 固定 tag → Release → 资产下载复核 → 准确候选 → 索引 Issue。中断重试先核对已有 commit/tag/资产，不覆盖同版本原件，不重复创建资产/申请。私有代码默认不公开，先做可审阅发布清单并取得明确公开发布授权。

首次官方收录依然需要维护者给申请加批准标签；作者助手不自我批准、不伪造维护者、不放宽生产审查。不把“已提交”说成“已上架”。已有来源的后续版本仅在明确批准的自动更新政策内无人值守，否则给出等待审核状态。等待结果不消耗无界轮询；回报源码、版本、摘要、Issue 和失败步骤，凭据不进入任何链接或工件。

### 最小验收矩阵

有 Git/gh 与两者都没有；已有 SDK 与缺 SDK；有游戏引用与缺引用；HTTP/SOCKS/无代理/不可用代理；已登录/未登录/权限不足；中文/英文需求；构建失败；源发布中断、资产已存在/冲突；候选检查失败、未审批、审批后自动发布；重试不覆盖原件不重复申请。至少真实演示一个纯设置/Tab 插件。游戏测试由用户完成，助手的结构化测试证据不得冒充游戏验收。
