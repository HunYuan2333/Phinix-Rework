## 已实现

- 主体构建包含 `Common/Extensions/17-PluginStore.Client.dll` 和自身中英文翻译；模块身份仍为 `phinix.plugin-store`，普通发现、注册、激活、关闭及用户停用设置均保留。宿主不引用商店实现类型。独立预览只在 `BuildPluginStorePreview=true` 时构建。
- 商店显示简介、标签、作者/许可、版本、兼容性、模块和依赖。宽窗口分为列表与详情，窄窗口上下排列；列表虚拟化，测量按状态/宽度缓存。无远端图片或 README 请求。
- 完整 Mod 打开固定 Steam 工坊 URL，自行订阅管理；GitHub 新包必须是 catalog v2 的 `phinix-dll` / `managed-dll-zip`，不写入 Mods、不创建 About。旧 v1 记录仍可在清理工具核对/卸载，旧界面停止提供新增安装。
- 在线目录严格绑定 stable/published/catalog、来源和完整摘要；与旧缓存独立的原子缓存只授权浏览。安装前和下载后以 `Cache-Control: no-cache` 绕过 Worker 元数据缓存核对目录；目录变化需重新审阅。下载复用固定路由、长度/hash、连接/空闲/总时限、取消和临时文件清理规则。
- 依赖求解有回溯和步数/包数/字节上限；拒绝不兼容、停用提供者、缺 Mod、模块/程序集身份冲突。检查未启用的旧 Mod，包括 LoadFolders 自定义路径和改名 DLL 的实际 CLR 身份；不自动迁移或删除它们。
- 安装、启停和卸载通过通用宿主服务，库存及启动快照分开。新代码重启后才执行；停用/待卸载/撤销都保留归属比较与依赖保护，卸载保留设置、业务数据和存档。

## 安装事务与审计

`IManagedExtensionInstallationService.Install` 使用启动时持有的租约。输入冻结 manifest/文件和 source/endpoint/catalog/artifact 身份；这些字段不是签名或远端授权，联网和用户确认仍由商店负责。宿主再次检查真实 PE、全部现有库存、已加载身份、兼容与联合依赖图；最多 32 个新包、总展开 256 MiB，拒绝覆盖安装或原位升级。

先保存 `transactions/in-<operation>.json` 的 preparing 日志，再暂存和逐文件校验；提交前重新读取库存及复核文件。原子替换日志为 committing 是提交决定，之后取消不回滚这批包。启动在加载前恢复：preparing 删除精确归属暂存，committing 完成整批目录/收据/期望状态。重复回放幂等。变动/未知文件、链接、冲突或损坏日志保留证据并关闭托管加载/写入。它没有业务物品迁移行为。

审计记录下载与安装阶段、稳定原因码、源/包/版本、snapshot/catalog/artifact 摘要、请求与事务编号；宿主还包含 UTC、启动 ID 和序号。公共日志不含路径、凭据或异常正文，内部详情在 DevMode 下输出。真实断电、磁盘持久性、Windows/macOS 和大包性能仍须验收，故障注入不能替代它们。

## 本地身份误报修复（2026-10-05）

游戏生成依赖计划时报告 `LocalIdentityUncertain`。只读复现扫描本机 Mod/工坊/Data，共 1427 次 DLL 检查，发现三个普通依赖库的 CLR 名称可以正常读取，但不满足新下载插件的完整入口/特性校验。本地重名检查错误复用了 `ManagedExtensionMetadataReader.Read`。

新增有界、不执行代码的 `ReadIdentity(bytes)`，仅用于本地 CLR 身份碰撞检查；下载包及宿主安装继续走原完整静态校验。重名 DLL、损坏字节、越界路径/链接和不可读文件仍拒绝。失败快照与界面增加模组 ID、模组内相对文件和底层原因码；结构化审计记录 `localMod`、仅文件名的 `localFile`、`localReason` 及来源，不输出目录路径或异常正文。

.NET 10 与 Mono 各通过 **580 + 15 + 18 + 16 = 629** 项，包括外部框架特性、改名 DLL 冲突、损坏字节、越界路径以及诊断/隐私；旧商店仍为 **677** 项。完整主体/商店构建通过，已有告警保留。生产本地检查对本机 **619 个已安装 Mod** 和真实 Playtest 目录通过；没有修改第三方文件，也不代表游戏界面/安装验收已通过。准确新增命令见本页 English 同节，其余构建/回归命令见前文。

退出游戏，使用整份更新的 `Output/phinix-rework` 替换主体包，再启动并重试依赖计划。本次修复无需更新 Worker 或测试资产，也不改业务协议、物品归属、已装包状态或存档。`--local-identities` 是显式只读诊断模式，无网络请求、写入或 DLL 加载；路径需按实际本机调整。
