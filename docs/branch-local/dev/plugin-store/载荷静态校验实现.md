# 载荷静态校验实现

日期：2026-10-03。分支：`dev`。这是第四批实施记录，接续[本地浏览预览](独立模块与本地浏览预览实现.md)。当前交付是可复用的静态载荷校验代码及回归，不是下载安装功能或正式包规范定稿。

## 已实现

`Extensions/PluginStore/Client/PayloadValidator.cs` 接受锁定的 GitHub 包记录、资产流与可选伴随清单。先有界读取并冻结输入，再比对索引声明的精确大小和原始 SHA-256，随后校验包结构。输入支持不可定位的分块流；调用者持有原流，校验器不关闭它。

- ZIP 清单必须在根 `phinix-package.json`。比对原始清单摘要和完整元数据，不从文件名猜入口。
- `About/About.xml` 的 packageId 和 supportedVersions 必须与锁定记录一致；XML 禁止 DTD 和外部解析器。
- 所有声明 DLL 必须位于 `Assemblies/<fileName>`，不能缺失、增加未声明 DLL 或藏到资源目录。实际程序集名称及四段版本必须与声明精确一致，文化标识必须为空。
- 有界检查 PE/CLI 头，要求 DLL、IL-only 标志且没有 native entry point。名称/版本由 BCL `AssemblyName.GetAssemblyName` 静态读取。受保护程序集规则与索引解析共用，改名后的 Utils/System/Unity/框架 DLL 仍被实际身份检查拒绝。
- DLL 模式必须另给清单并核实摘要；本批不生成最小模组壳。
- 返回只读报告，锁定原包记录、资产摘要及按路径排序的逐文件长度/摘要。报告不携带安装授权；后续读取不同或已变更文件必须重新核实。

没有使用 `Assembly.Load`、执行待检 DLL、构建作者工程或执行脚本。BCL 方法临时写入系统临时目录的随机 `CreateNew` 文件，不使用归档路径，完成/失败/取消时删除；临时文件 IO/删除失败向调用者传播，不记作成功。接口依据见 [Microsoft 文档](https://learn.microsoft.com/en-us/dotnet/api/system.reflection.assemblyname.getassemblyname)。当前 DLL 身份检查不解析程序集引用、TargetFramework 属性、模块入口类型/特性或完整 IL，不能由此证明 RimWorld/Unity API 兼容性、安全性或真实入口可用。

## 当前 ZIP 开发规则

| 项目 | 规则 |
| --- | --- |
| 根布局 | `About`、`Assemblies`、`Defs`、`Patches`、`Languages`、`Textures`、`Sounds`；根清单及 LICENSE/README 的指定常见文件名 |
| 资源文件 | `.xml`、`.txt`、`.md`、`.png`、`.jpg`、`.jpeg`、`.dds`、`.wav`、`.ogg`；不是任意文件白名单 |
| 尚未支持 | 外层包目录、多版本目录、`LoadFolders.xml`、额外 DLL、原生/混合 DLL、安装脚本；明确拒绝，不隐式改写布局 |
| 路径 | 相对 `/` 路径、Unicode NFC，最长 240 字符/16 层/单段 160 字符；禁止反斜杠、`.`/`..`、空段、驱动/ADS、控制字符、Windows 保留名及末尾空格/点 |
| 归档身份 | 大小写别名、重复项、文件与目录碰撞、Unix 链接/特殊项及 Windows reparse/设备属性均拒绝；显式父目录允许在子文件之后出现 |
| 限额 | 资产至多 128 MiB；4096 条目；单文件 64 MiB；总声明展开大小 256 MiB |
| 压缩 | 单项展开量不得超过 `max(1 MiB, compressedLength × 200)`；实际读取同时受声明长度约束 |
| 小文件 | 清单 2 MiB、About 1 MiB；取消在流读取/条目/身份检查之间检查 |

规则故意限制首版能处理的形态，不代表所有合法 RimWorld 模组都能入库。归档库负责 ZIP 格式/解压解析；资产摘要、逐项路径与实际读取长度另行检查，不声称已实现完整 ZIP 格式审计或所有 CRC 校验。
