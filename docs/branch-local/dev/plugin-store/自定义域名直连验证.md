日期：2026-10-04。分支：`dev`。[English](CustomDomainDirectAccess.md)。

这些证据支持先沿用自定义域名 Worker + 私有 R2，不必先增加服务器。它只证明当前主机/网络及既有静态测试服务；不证明插件 gateway、Unity/Mono 传输、大陆多地区可达性、长期稳定性、GitHub 冷回源、大 ZIP 或费用预算。仍需为真实插件 Worker 绑定专用域名，保留既有测试服务用于对比。

生产客户端通过选定的 repository 自定义域名读取元数据和包字节。GitHub Release 跳转继续由 gateway 内部处理；玩家不应依赖直连 GitHub/R2 或内部 Wrangler 运维桥接。固定源/快照/hash、HTTPS、拒绝客户端重定向及包校验规则继续保留。当前带临时认证的 PoC 不是公开游戏入口，不能简单删除令牌/到期约束就宣称游戏验收通过。

下一步：选定域名下的独立仓库主机名；绑定真实 gateway，保留缓存历史并验证 TLS；关闭代理/TUN 后测试受控真实 catalog 和 ZIP；补大陆不同运营商/地区样本；再验收游戏联网与实际包大小。只有测量表明需要时再增加其他区域分发入口。单个域名成功是继续试运行的证据，不是全网可用保证。

首页精确测试命令（文件下载沿用这些标志，另加 6 MiB 大小上限和 30 秒总超时）：

```sh
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u http_proxy -u https_proxy -u all_proxy \
  curl --noproxy '*' --connect-timeout 5 --max-time 12 --silent --show-error \
  --output /dev/null --write-out 'http=%{http_code} time=%{time_total}\n' \
  https://cf-test.hunyuan2333.com/
```

Cloudflare 支持以 Worker 作为自定义域名的源，并管理相关 DNS/证书配置，见[官方文档](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/)。首轮静态测试未创建域名绑定；下方记录随后获授权的真实 gateway 绑定。
