## 实现前的宿主缺口（已在第一批补齐）

原先 ClientExtensionAbstractions 没有语言/翻译接口。ManagedExtensionRuntime 会验证 manifest.Resources 的文件，但没有将这些文件注册成语言资源；安装成功不等于能调用 Translate()。原先 Playtest 在 DLL 中自选中英文词典；1.3.0 已改用包内 JSON。主体内置语言走 RimWorld 原有 Languages，这也不意味着安装在 SaveData 中的托管包能被原生 Mod 扫描。

工坊条目只提供商店名称/简介和链接。工坊 Mod 的语言文件、加载和 UI 翻译由 RimWorld 及作者负责；Phinix 不导入或管理它的翻译。

## 作者结构：一种语言一个 JSON

```text
my-plugin/
  manifest.json
  Assemblies/
    My.Plugin.dll
  Resources/
    Localization/
      zh-CN.json
      en-US.json
      ja-JP.json
```

下载载体是完整 ZIP，安装后保留该文件夹结构。作者可只提供任一语言文件，多语言可选。统一 UTF-8 JSON，避免 JSON/XML/YAML 三套解析；文件名按规范语言标识命名，大小写输入由打包工具规范化。

```json
{
  "schemaVersion": 1,
  "locale": "zh-CN",
  "display": {
    "name": "测试插件",
    "summary": "验证插件发现、Tab 和白银操作。",
    "changelog": "新增语言文件支持。"
  },
  "strings": {
    "tab.title": "插件测试",
    "silver.give": "获得 100 白银",
    "counter.value": "已操作 {0} 次"
  }
}
```

- schemaVersion/locale/display/strings 是语言文件根字段；display 的 name/summary/changelog 是展示字段，strings 是 UI key 到文字的映射。字段和 key 不允许重复。
- 一个语言可以缺少个别 display 字段/UI key，逐项回退；所有语言合计必须有有效 name 和 summary。changelog 可完全省略，商店显示“暂无更新说明”。strings 可以为空，例如只提供商店元数据的插件。
- 可用标识采用 language[-Script][-REGION]（语言 2–3 字母、脚本 4 字母、地区 2 字母或 3 数字），例如 en-US、zh-CN、zh-Hant、ja-JP。边界规范化，规范化后重复语言拒绝。不要求作者使用 RimWorld 目录名。
- 新 manifest 用显式 localization 声明列出语言文件及可选 defaultLocale；每个文件同时属于有摘要/长度的 Resources 声明。默认语言必须在提供集合中；单文件不必指定默认。打包工具生成声明，宿主只读取声明归属的文件，不扫描任意外部目录。
- 每包最多 16 种语言；文件最多 128 KiB，全部语言文件最多 1 MiB；显示名 160、简介 1024、changelog 8192 个 UTF-16 单元，全部展示文字最多 32768 个单元；UI 最多 2048 个不同 key、每个值最多 8192 个单元。保留文档/总包现有边界，不为加入语言提高全目录/ZIP 限额。
- 简介、changelog、UI 文本允许换行/制表；不允许其他控制字符、空白值、异常代理字符或脚本。文字按纯文本显示。格式占位符使用 {0} 等编号及 {{ / }} 转义；每个 key 的已有译文必须使用相同占位符集合，缺 key 可回退。

目录直接使用新 v3：每条记录包含 localization.translations[locale] 的 name/summary/changelog 与可选 defaultLocale。发布工具从语言文件提取 display，UI strings 留在 ZIP 内；商店浏览不下载完整包或额外语言文件。顶层旧 name/summary 展示字段不做兼容映射；包发现、依赖与归属使用稳定 ID，manifest 的规范信息不随显示语言变化。托管 manifest 固定 schemaVersion=1，增加严格解析的可选 localization 字段；没有声明表示该包不提供本服务的语言资源，不存在旧格式映射。语言文件固定 schemaVersion=1。准确声明已与独立校验器同步。目录 v3 仍待实现。

## 本地应用：宿主负责加载，插件负责使用 key

1. 安装器验证整个 ZIP、清单及声明资源的长度/摘要，安装到既有包目录；不在下载时执行 DLL。
2. 宿主加载前由已验证归属映射读取语言文件，做结构、key/占位符及边界检查，生成按包隔离的只读词典。语言声明/数据有误要给出包 ID、文件、阶段和稳定原因码，不拖垮其他插件。
3. 在插件 Activate 前注册通用 IClientLocalizationService（契约在 ClientExtensionAbstractions），插件通过 ForModule(this) 得到 IClientLocalizer。服务从已注册模块/程序集归属解析资源根，不接受插件传入任意磁盘路径。
4. 插件绘制 UI 时用 localizer.Text("silver.give")，含参数时用 localizer.Format("counter.value", count)。翻译对象保存于该插件的 Tab/provider，TabLabel 属性动态取文本；接口不会自动翻译 DLL 中写死的文字，作者必须使用 key。
5. 游戏语言在主线程映射为规范 locale；加载文件/纯数据解析可后台执行。Text/Format 使用已发布的不可变语言快照，后台取值不调用 Unity/Verse 翻译设施。
6. 精确匹配 → 同语言合适变体/基础语言 → 可用英语 → 作者默认 → 稳定顺序的实际语言，逐 key 回退。简繁中文的文字体系规则明确，不在同语言匹配阶段误选相反文字体系。仅一种语言时直接使用它；全缺 key 返回调用方默认文字或可见 key，并限频记录诊断，不输出空白。
7. 宿主主线程发布 LanguageChanged；插件清理自己的测量/布局缓存，下一次绘制取新文案。停用时 Shutdown 释放 localizer/事件订阅，卸载后的词典随生命周期释放，不删除设置/存档。切语言无需重新安装或重启。

内置、官方拆包和第三方使用同一服务。内置包资源也必须通过通用模块归属解析器接入；不能给官方插件专用取翻译分支。此服务由宿主提供，不依赖商店是否启用，不注入全局 RimWorld 翻译表，不覆盖其他包的 key。按包隔离用于正确取值和避免名称冲突，不宣称 CLR 内第三方 DLL 因此获得安全沙箱。
