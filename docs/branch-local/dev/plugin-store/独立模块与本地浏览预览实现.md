# 独立模块与本地浏览：第三批实现

日期：2026-10-03。分支：`dev`。在本轮环境/路径增量之后继续推进步骤 4，产出可构建的本地预览候选包。不是阶段里程碑 A 的实际游戏验收，不包含 GitHub 网络、Steam 或安装。

## 当前可操作流程

独立包身份为 `hunyuan2333.phinixpluginstore`，模块 ID 为 `phinix.plugin-store`。模块按原有 Register/Activate/Shutdown 运行，Register 只注册 IClientSettingsPanelProvider；Activate 注入通用环境、窗口、dispatcher 和日志服务。不要求 Chat/Trade/Inventory 前置，没有 Host 专用打开函数或具体插件引用。

候选包位于 `Output/phinix-plugin-store-preview`，构建只复制 `PluginStore.Client.dll`、About 和两种语言的 Keyed XML。没有加入主包发行目录，没有移除原官方功能 DLL，也没有创建或发布远端资源。使用方法见 [中文预览说明](../../../../Extensions/PluginStore/README.zh-CN.md) / [English](../../../../Extensions/PluginStore/README.md)。需要配套更新宿主和客户端抽象 1.2.0。

游戏端候选入口在 Phinix 模组设置，供未登录/主菜单使用；实际入口可用性待游戏测试。填写本地 JSON 的完全限定路径和源 ID，载入索引，按 ID/名称搜索，选择一个版本查看元信息，再显式生成完整依赖计划。窗口显示来源、提交、索引摘要、依赖优先顺序、声明下载体积和外部前置。示例采用仓库链样例及 `test.local`，不编造正式默认源。

工坊条目只展示渠道、ID 与 URL，同时说明 Steam 入口待验证；没有链接到系统浏览器，也没有伪造订阅/安装结果。计划是预览，没有下载确认或提交入口。索引读取有 2 MiB 上限，拒绝相对/网络路径；读取和求解都在后台，不在 Draw 执行 IO。游戏事实仍在明确主线程动作中捕获，错误不会越过窗口。

## 任务和 UI 边界

[StoreBrowserController.cs](../../../../Extensions/PluginStore/Client/StoreBrowserController.cs) 保存线程安全、不可变的权威快照。终态先写入控制器，不需要 UI 打开或 dispatcher 回调。关闭窗口不会取消；模块关闭显式取消并清空状态。无效刷新保留旧有效索引；刷新后当前计划失效，旧持有计划仍不可变。选择来源快照发生改变时拒绝旧的规划请求。

任务有十秒监视器、明确取消、generation 隔离和最多两个未完成读取。同步文件 IO 可能不能立即中断，后台任务可继续退出，但迟到完成/异常不覆盖取消、超时、新任务或 Shutdown。读取未退出时不会无限创建线程/任务；达到上限报告 PendingWorkers。全栈诊断保存在快照，UI 观察到时经 host 日志输出。

[PluginStoreWindow.cs](../../../../Extensions/PluginStore/Client/PluginStoreWindow.cs) 使用标准窗口/设置入口、屏幕安全区、外层滚动、可见行裁剪，以及数据/语言/宽度驱动的缓存。所有出口还原 Font/Anchor/GUI.color/GUI.enabled 和滚动状态。长列表行按像素截断并保留 Tooltip；外部元信息剥除 rich text。关闭模块的窗口操作经 dispatcher，任务 Shutdown 不依赖该回调成功。

布局原语回归通过不等于实际文字排版通过；分辨率、UI scale、语言和极窄窗口仍须游戏验收。当前没有新增几何辅助 API。
