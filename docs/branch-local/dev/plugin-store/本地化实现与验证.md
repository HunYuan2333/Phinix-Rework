## 已实现

- 共享 `ExtensionLocalization` 严格解析 UTF-8 JSON，限制语言/文件/词典规模，规范语言文件名，逐字段/逐 key 回退，匹配简繁脚本，核验编号参数一致性。仅英文、仅中文、仅日文等均合法；未知字段、重复、标记、异常文字/参数和摘要/长度不符拒绝。
- 托管 manifest 固定 schemaVersion=1，增加可选 `localization: {files:["Resources/Localization/en-US.json"], defaultLocale:"en-US"}`。每个文件同时在 resources 中声明长度/SHA-256。没有声明表示不提供本服务的语言资源；defaultLocale 可省略，提供时必须存在。语言 JSON 固定 schemaVersion=1。
- ClientExtensionAbstractions 1.7.0 新增 `IClientLocalizationService.ForModule(this)` 和可释放的 `IClientLocalizer`，提供 Text/Format/Locale/LanguageChanged。绑定与游戏语言发布限主线程，文字读取使用冻结数据。缺 key 返回调用者默认或可见 key，日志限频；参数和结果有界。
- 宿主在 Activate 前提供服务，主线程读取并跟随游戏语言。资源来自已注册模块/程序集归属，不允许传入任意路径；插件重载 Equals 也不会混淆实例。托管包绑定已核验的启动归属，普通随包 DLL 读取显式伴随清单。无商店依赖、官方插件专属分支或 RimWorld 全局语言注入。
- 通用生命周期钩子在激活失败和 Shutdown 后释放句柄/订阅，插件抛异常也会清理。关闭与下次启动卸载不删除设置/存档，不在当前会话热卸载 CLR；启动域 Dispose 后释放保留的包词典。
- ZIP 校验、宿主安装和启动都在使用 DLL 前验证语言。启动冻结词典，之后改磁盘文件不改变页面查询。托管日志保留包/事务关联并增加所属相对 resourcePath；本地化日志含 UTC、序号、模块、原因码、相对文件和缺译/格式 key，不输出绝对路径或全文。
- ManagedPackageTool 支持重复 --language-file、可选 --default-locale 和 --bundle-output。随包输出为 DLL、邻接 `<assembly>.dll.localization.json`、`Resources/<packageId>/Localization/`，避免多个插件同名语言文件互相覆盖。伴随清单含 schemaVersion=1、assemblyName、resources、localization，使用与托管包同一套声明和解析；缺伴随清单表示无语言包。输出存在就拒绝，提供 --host-assembly 时复核外部精确 CLR 身份。
- Playtest 1.3.0 改用 en-US/zh-CN JSON，实现动态 Tab、按钮、确认框、计数和结果。可信 bot 校验器已同步共享语言与严格载荷代码，24 份快照的 provenance 摘要一致。工坊 Mod 自己的语言仍由作者/RimWorld 负责。
