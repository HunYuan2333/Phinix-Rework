## 测试计划

- 协议：packet/envelope 编解码、不支持类型拒绝或降级
- 发现：反射发现合法 module、重复注册清晰报错、坏扩展不拖垮启动
- Pipeline：三条主链分发行为清晰、未知 item payload 软失败、自定义渲染
- 兼容性：新客户端连旧服务器自动进入 legacy 模式
- 架构回归：新增 official extension 不修改 core pipeline；移除 extension 后 host 仍可启动
