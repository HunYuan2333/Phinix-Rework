# 聊天主题配色方案

> 2026-06-21，基于《聊天UI重构与美化方案.md》§3 细化。
>
> **本文档是方案文档，不是已实施记录。**

---

## 0. 目标

将聊天 UI 的所有颜色从硬编码 `static readonly` 改为外部 XML 主题文件驱动，让用户无需改代码即可自定义配色。

**MVP 范围**：
- `ChatTheme` 静态容器（~15 个颜色字段）
- `ThemeLoader`：读 XML → 解析 → 填充 `ChatTheme`
- 默认主题文件随 mod 分发
- 用户主题放 RimWorld Config 目录，覆盖默认
- 设置面板加"重载主题"按钮

**不在 MVP 内**：
- 颜色选择器 UI（后续可加）
- 主题下拉选择（后续可加）
- 主题热重载（MVP 只支持手动点"重载"按钮）

---

## 1. 文件格式

### 1.1 XML Schema

```xml
<?xml version="1.0" encoding="utf-8" ?>
<PhinixChatTheme>
  <!-- 消息区 -->
  <color key="selfMessageBg"       r="0.15" g="0.25" b="0.40" a="0.15" />
  <color key="otherMessageBg"      r="0.00" g="0.00" b="0.00" a="0.00" />
  <color key="mentionText"         r="0.40" g="0.70" b="1.00" a="1.00" />
  <color key="mentionSelfBg"       r="0.30" g="0.30" b="0.15" a="0.15" />
  <color key="timestamp"           r="0.60" g="0.60" b="0.60" a="0.70" />
  <color key="pendingMessage"      r="1.00" g="1.00" b="1.00" a="0.80" />
  <color key="deniedMessage"       r="0.94" g="0.28" b="0.28" a="1.00" />
  <color key="hoverHighlight"      r="1.00" g="1.00" b="1.00" a="0.10" />

  <!-- 回复引用 -->
  <color key="replyQuoteBorder"    r="0.30" g="0.50" b="0.80" a="0.70" />
  <color key="replyQuoteBg"        r="1.00" g="1.00" b="1.00" a="0.04" />
  <color key="replyQuoteText"      r="0.60" g="0.60" b="0.60" a="1.00" />

  <!-- notice -->
  <color key="noticeAccent"        r="0.90" g="0.70" b="0.20" a="0.90" />
  <color key="noticeBg"            r="0.20" g="0.15" b="0.08" a="0.15" />
  <color key="noticeProgress"      r="0.30" g="0.60" b="1.00" a="0.80" />
  <color key="noticeBannerBg"      r="0.10" g="0.15" b="0.20" a="0.85" />

  <!-- 输入区回复条 -->
  <color key="inputReplyBorder"    r="0.30" g="0.50" b="0.90" a="0.80" />
  <color key="inputReplyBg"        r="0.20" g="0.30" b="0.50" a="0.10" />

  <!-- 分隔线 -->
  <color key="separator"           r="1.00" g="1.00" b="1.00" a="0.08" />
</PhinixChatTheme>
```

### 1.2 设计约束

- 每个颜色一个 `<color>` 元素，属性式写法，紧凑
- `key` 属性是颜色唯一标识，C# 端用字符串映射到 `ChatTheme` 字段
- `r`/`g`/`b`/`a` 四个属性，取值 `0.0`–`1.0`（和 Unity Color 一致）
- 缺失的颜色用代码默认值兜底，不报错
- 多余的 `<color>` 忽略，不报错
- `a` 属性可省略，默认 `1.0`

### 1.3 为什么选 XML 不选 JSON

| 维度 | XML | JSON |
|------|-----|------|
| RimWorld 原生 | ✅ `XmlReader`/`XmlDocument` 内置 | ❌ 需引入 `System.Text.Json` NuGet |
| net472 兼容 | ✅ | ⚠️ 需额外包 |
| 代码库已有模式 | ✅ `Server/Config.cs`、`Trade/Store.cs` 均用 `XmlReader` | ❌ 无先例 |
| 用户编辑 | 稍啰嗦但可接受 | 更简洁 |
| Mod 生态 | XML patch 是 RimWorld 标准操作 | 不支持 |

## 2. 文件位置与加载顺序

### 2.1 目录结构

```
Mod 分发（只读）：
  Client/Themes/
    default.xml          ← 随 mod 发布的默认主题

用户自定义（可读写）：
  {GenFilePaths.SaveDataFolderPath}/Phinix/Themes/
    custom.xml           ← 用户复制 default.xml 改的
    dark.xml             ← 用户下载的暗色主题
    high-contrast.xml    ← 用户下载的高对比主题
```

### 2.2 加载优先级

```
1. 先加载 mod 目录 Client/Themes/default.xml   → 填充 ChatTheme 默认值
2. 再扫描 Config 目录 Phinix/Themes/*.xml      → 覆盖 ChatTheme
3. 如果 Config 目录有多个 .xml，按文件名字典序加载，后者覆盖前者
4. 设置面板可选当前主题文件名（MVP 不做选择器，默认加载所有）
```

### 2.3 加载时机

- **mod 初始化时**：`BuiltInChatClientExtension.Register` 或 `Activate` 阶段调 `ThemeLoader.Load()`
- **用户点"重载主题"按钮**：重新执行 `ThemeLoader.Load()`
- **不做每帧检查**（§8 性能）

## 3. 架构设计

### 3.1 ChatTheme 静态容器

**文件**：`Extensions/Chat/Client/ChatTheme.cs`（新增）

```csharp
namespace Phinix.ChatExtension.Client
{
    internal static class ChatTheme
    {
        // 消息区
        public static Color SelfMessageBg = new Color(0.15f, 0.25f, 0.40f, 0.15f);
        public static Color OtherMessageBg = new Color(0f, 0f, 0f, 0f);
        public static Color MentionText = new Color(0.4f, 0.7f, 1.0f, 1.0f);
        public static Color MentionSelfBg = new Color(0.3f, 0.3f, 0.15f, 0.15f);
        public static Color Timestamp = new Color(0.6f, 0.6f, 0.6f, 0.7f);
        public static Color PendingMessage = new Color(1f, 1f, 1f, 0.8f);
        public static Color DeniedMessage = new Color(0.94f, 0.28f, 0.28f, 1f);
        public static Color HoverHighlight = new Color(1f, 1f, 1f, 0.1f);

        // 回复引用
        public static Color ReplyQuoteBorder = new Color(0.3f, 0.5f, 0.8f, 0.7f);
        public static Color ReplyQuoteBg = new Color(1f, 1f, 1f, 0.04f);
        public static Color ReplyQuoteText = new Color(0.6f, 0.6f, 0.6f, 1f);

        // notice
        public static Color NoticeAccent = new Color(0.9f, 0.7f, 0.2f, 0.9f);
        public static Color NoticeBg = new Color(0.2f, 0.15f, 0.08f, 0.15f);
        public static Color NoticeProgress = new Color(0.3f, 0.6f, 1f, 0.8f);
        public static Color NoticeBannerBg = new Color(0.1f, 0.15f, 0.2f, 0.85f);

        // 输入区回复条
        public static Color InputReplyBorder = new Color(0.3f, 0.5f, 0.9f, 0.8f);
        public static Color InputReplyBg = new Color(0.2f, 0.3f, 0.5f, 0.1f);

        // 分隔线
        public static Color Separator = new Color(1f, 1f, 1f, 0.08f);

        // ---- key → 字段映射表 ----
        private static readonly Dictionary<string, Action<Color>> Setters = new Dictionary<string, Action<Color>>
        {
            { "selfMessageBg",    c => SelfMessageBg = c },
            { "otherMessageBg",   c => OtherMessageBg = c },
            { "mentionText",      c => MentionText = c },
            // ... 其余同理
        };

        internal static void Apply(string key, Color color)
        {
            if (Setters.TryGetValue(key, out var setter))
            {
                setter(color);
            }
        }

        internal static void ResetToDefaults()
        {
            // 重新赋值所有字段为代码默认值
            SelfMessageBg = new Color(0.15f, 0.25f, 0.40f, 0.15f);
            // ... 其余同理
        }
    }
}
```

**关键设计**：
- 字段是 `static`（非 `readonly`），主题加载时赋值
- 每个字段的**代码默认值**就是当前硬编码值——如果 XML 缺失该 key，代码默认值兜底
- `Setters` 字典做 key→字段映射，`Apply` 方法供 `ThemeLoader` 调用
- `ResetToDefaults` 在重新加载前清空上次的主题覆盖

### 3.2 ThemeLoader

**文件**：`Extensions/Chat/Client/ThemeLoader.cs`（新增）

```csharp
internal static class ThemeLoader
{
    private static readonly string ModThemesDir = "Themes";           // mod 目录下
    private static readonly string UserThemesDir =                    // Config 目录下
        System.IO.Path.Combine(GenFilePaths.SaveDataFolderPath, "Phinix", "Themes");

    internal static void Load()
    {
        ChatTheme.ResetToDefaults();

        // 1. 加载 mod 目录默认主题
        string defaultPath = System.IO.Path.Combine(modRootDir, ModThemesDir, "default.xml");
        if (System.IO.File.Exists(defaultPath))
        {
            LoadFile(defaultPath);
        }

        // 2. 扫描用户主题目录
        if (System.IO.Directory.Exists(UserThemesDir))
        {
            foreach (string path in System.IO.Directory.GetFiles(UserThemesDir, "*.xml")
                                                  .OrderBy(p => p))
            {
                LoadFile(path);
            }
        }
    }

    private static void LoadFile(string path)
    {
        try
        {
            using (XmlReader reader = XmlReader.Create(path))
            {
                while (reader.Read())
                {
                    if (reader.NodeType == XmlNodeType.Element && reader.Name == "color")
                    {
                        string key = reader.GetAttribute("key");
                        float r = ParseFloat(reader.GetAttribute("r"), 0f);
                        float g = ParseFloat(reader.GetAttribute("g"), 0f);
                        float b = ParseFloat(reader.GetAttribute("b"), 0f);
                        float a = ParseFloat(reader.GetAttribute("a"), 1f);
                        if (!string.IsNullOrEmpty(key))
                        {
                            ChatTheme.Apply(key, new Color(r, g, b, a));
                        }
                    }
                }
            }
        }
        catch (Exception ex)
        {
            // 记录日志，不中断加载
            Log.Error($"[Phinix] Failed to load theme file '{path}': {ex.Message}");
        }
    }

    private static float ParseFloat(string value, float defaultValue)
    {
        if (float.TryParse(value, NumberStyles.Float, CultureInfo.InvariantCulture, out float result))
        {
            return Mathf.Clamp01(result);
        }
        return defaultValue;
    }
}
```

**关键设计**：
- `XmlReader` 流式解析，不加载整个文档到内存（§3.6 资源边界）
- `try-catch` 包裹单个文件加载，一个文件坏不阻止其他文件加载（§3.5 错误隔离）
- `ParseFloat` 用 `InvariantCulture` 避免区域设置问题
- `Mathf.Clamp01` 确保值在 0-1 范围内
- `a` 属性可省略，默认 `1.0`
- mod 目录路径需要从插件上下文获取（见 §3.3）

### 3.3 mod 目录路径获取

`ThemeLoader` 需要知道 mod 的根目录来找到 `Themes/default.xml`。RimWorld 中获取当前 mod 目录的方式：

```csharp
// 方式 A：通过 ModContentPack
ModContentPack mod = LoadedModManager.RunningMods.FirstOrDefault(m => m.Name == "Phinix Rework");
string modRootDir = mod?.RootDir;

// 方式 B：通过 Assembly 位置推断
string assemblyPath = typeof(ChatTheme).Assembly.Location;
string modRootDir = System.IO.Directory.GetParent(assemblyPath)?.Parent?.FullName;
```

推荐**方式 B**——不依赖 mod 名字符串匹配，更健壮。

### 3.4 现有代码改动

现有代码中的 `static readonly Color` 改为读 `ChatTheme` 字段：

| 文件 | 当前 | 改后 |
|------|------|------|
| `ChatMessageList.cs` | `private readonly Color pendingMessageColour = new Color(...)` | 删除，改用 `ChatTheme.PendingMessage` |
| `ChatMessageList.cs` | `private readonly Color deniedMessageColour = new Color(...)` | 删除，改用 `ChatTheme.DeniedMessage` |
| `ChatMessageList.cs` | `private readonly Color backgroundHighlightColour = new Color(...)` | 删除，改用 `ChatTheme.HoverHighlight` |
| `ChatMainTabProvider.cs` | 硬编码 `Color.grey` | 改用 `ChatTheme.Timestamp` |

**注意**：`NoticeBannerProvider.Draw` 里的 `new Color(...)` 必须移到 `ChatTheme` 静态字段。Draw 路径每帧调 `new Color()` 违反 §8.3。

## 5. §8 性能合规

### 5.1 Draw 路径零分配

`ChatTheme` 字段是 `static Color`（值类型），读字段 = 读栈上 16 字节，零分配。和当前 `static readonly Color` 性能完全一致。

### 5.2 加载路径不在 Draw 路径

`ThemeLoader.Load()` 只在以下时机调用：
- `BuiltInChatClientExtension.Activate`（mod 初始化，一次性）
- 用户点"重载主题"按钮（事件驱动，非每帧）

加载路径的 `new Color()` / `XmlReader` / 字符串解析都不影响 Draw 性能。

### 5.3 @高亮文本缓存

@高亮在 `recalculateMessageRects`（脏标记触发，非每帧）时用 `ChatTheme.MentionText` 处理一次，存入 `CachedMessageDisplay.FormattedMessage`。Draw 路径只读缓存字符串。

## 7. 错误处理（§3.5）

| 场景 | 处理 |
|------|------|
| `default.xml` 不存在 | 用代码默认值，不报错 |
| 用户主题目录不存在 | 只加载默认主题，不报错 |
| XML 格式错误 | `try-catch` 跳过该文件，记录 `Log.Error`，继续加载其他文件 |
| 颜色值超出 0-1 | `Mathf.Clamp01` 钳制 |
| `a` 属性缺失 | 默认 `1.0` |
| 未知 key | 忽略，不报错 |
| key 已存在 | 后加载的文件覆盖先加载的 |

## 8. 后续扩展路径

| 扩展 | 复杂度 | 依赖 |
|------|--------|------|
| 主题下拉选择器 | 低 | 扫描目录列 .xml 文件名，存到设置 `chat.theme.current` |
| 颜色选择器 UI | 中 | 读 `ChatTheme` → 在设置面板渲染颜色块 + Slider → 写回 XML |
| 主题热重载 | 低 | 文件系统 Watcher 监听目录变化 → 调 `ThemeLoader.Load()` |
| 主题分享 | 无 | 用户直接分享 .xml 文件 |
| 第三方主题包 | 无 | 其他 mod 把 .xml 放到 Config/Phinix/Themes/ 即可 |

## 9. 验证清单

- [ ] 删除 `Client/Themes/default.xml` → UI 用代码默认值，不崩溃
- [ ] `default.xml` 缺少某个 key → 该颜色用代码默认值
- [ ] `default.xml` 颜色值写错（如 `r="abc"`）→ 跳过该颜色，不崩溃
- [ ] 用户主题目录有 `custom.xml` → 覆盖默认主题对应颜色
- [ ] 用户主题目录有多个 .xml → 按文件名字典序加载，后者覆盖前者
- [ ] 点"重载主题"按钮 → 立即生效，无需重启
- [ ] Draw 路径无 `new Color()`（profiler 确认）
- [ ] 所有颜色值 Clamped 到 0-1
