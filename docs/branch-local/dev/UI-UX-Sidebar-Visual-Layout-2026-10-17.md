## 主题使用与限制

外壳 `ui.background`，卡片 `ui.surface`，边框/分隔 `ui.separator`，本人标识 `ui.accent`（沿用input.focus回退），正文/标题 `ui.text.primary`，导航/列表选中与Primary按钮继续用公共既有角色。所有值从当前主题快照获取，无截图蓝紫色或硬编码的专用配色。未修改全局renderer/padding。

仓库default.xml是暖色主题，用户截图呈蓝紫色，不能把截图配色当作源码默认值。按默认XML不透明sRGB相对亮度公式（通道线性化后0.2126R+0.7152G+0.0722B，亮度比加0.05）核算：正文/Surface约14.51:1，Separator/Surface约2.20:1，Surface/Background约1.04:1，Accent/Surface约8.87:1。因此底色差异本身不能承担清晰分区，这轮也通过卡片轮廓、边距、标题及原有选中条组织内容。装饰边界2.20不是3:1达标声明；默认主题进一步状态改版仍属UX2-04，不擅自覆盖用户主题。透明自定义主题、不同缩放和游戏底图必须实机核验。
