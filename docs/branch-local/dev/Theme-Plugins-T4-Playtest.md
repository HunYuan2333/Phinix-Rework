## 当前客户端

1. 使用当前 T3 完整客户端输出并重启，避免单独混装 SDK/内置 DLL。在开发者模式下通过商店本地 ZIP 入口安装红包/人才贸易 1.1.2，按需安装 Example 1.0.3，再重启。已有其他来源包时遵守既有来源规则，不覆盖收据或 journal。
2. 主题窗口确认红包、人才贸易各有 panel/highlight/accent 三项，Example 有 panel/counter 两项；编辑并应用后应热更新，不要求再次重启。
3. 导入 Phinix/local-theme-samples/2026-10-11/08-plugin-t4.xml 并应用。观察两个插件面板、悬停和强调，以及 Example 面板/计数文字。切换回默认主题，确认颜色恢复。
4. 缺少专属键的部分主题应回退共享角色/注册默认值。未安装 Example 时其文件键应保留为未使用项；安装/启用后再生效。停用维护插件并重启后注册移除，用户值仍保留，重新启用后恢复。
5. 检查按钮悬停/按下/禁用、输入焦点与数量输入、复选框、图标原色；切换主题不清空输入、滚动与选择。按原有正常使用流程确认红包详情/公告/交付和人才贸易各面板可用，不为配色验收额外发起交易。
6. 若激活失败，保留商店摘要和游戏日志；不能仅凭包安装成功判定模块已激活。
