# B19 游戏验收（待用户执行，2026-10-12）

使用 B19 Host + Example 1.0.26，同一批 DLL 替换后完全重启；候选路径/SHA 见构建 manifest。没有发布或自动安装。以下逐项记录通过/失败，源码编译和隔离测试不代替游戏证据。

1. 单向赠送：赠送方无物品可收，收到真实完成事件后不出现空交付错误、不生成空 pod；接收方真实收到全部物品。继续检验 direct 与 inventory、空取消返回、重复完成与断线/重连。非空坏 payload 保持失败/pending，不能以“无需交付”确认。旧版本用户需要修复 DLL，不是换主题。
2. 设置→主题：选择草稿主题后不自动应用；切回保留编辑值；左右 pane 标题/检索/操作固定，列表和右侧编辑独立滚动。宽、窄、极短窗和不同 UI scale 不截文字/不重叠，选择后正确关闭选择器。
3. 选颜色→RGBA 原文不完整/超界→显示无效并禁用 Apply/Export，原合法预览保留；修正→预览更新→应用真实热变色。float 文本/滑块一致，拖动不吞 IME；未知 keys 保留，clear 与 explicit inherit 按来源显示；刷新/插件撤销后旧操作失效，重新注册能显示。
4. Editor 中 Example 贡献计数操作只修改 Example；普通 Example 窗口的滑块、未完成数值原文和颜色样本由 Host 正常显示。贡献模块停用/窗口关闭/语言或主题变更后的旧菜单、确认不得执行。
5. 草稿→导出：metadata/path→导出 ZIP→真实完整路径，重复目标拒绝；桌面打开目录失败仍可复制路径、导出成功保留。metadata 保存失败不反向宣称 ZIP 未写。导出包含自定义、unknown/inherit；关闭子窗口/根窗口/返回主菜单后无残留 session。
6. 商店→本地主题包→检查导出 ZIP→安装→刷新→主题选择→应用；再试更新/卸载确认/取消、选中包失踪、损坏/缺文件/变体删除、profile intent/fallback 与恢复故障注入。此项 T5 后端已有，不因新 UI 自动算验收通过。
7. B18 默认按钮与侧栏对比，前批商店/库存完整操作、fcitx、左右时间戳和动态导航继续各自验收；此前用户确认的可见排版结论不扩大到业务流程。
