## 一轮人才全流程

1. **导航与布局**：直接交易/市场/租赁来回切换，固定导航/搜索/筛选，左列表与右详情操作保持清楚；窄窗和不同UIscale，中英长姓名/summary不截断。搜索和表单数字切分支保留，具体Pawn选择重选；无变化轮询/心跳不频繁撤销确认。
2. **直接交易双方**：发起、接受/拒绝→选人/添加、移除、白银草稿、提交→双方锁定→实际成交交付核对。缺种族阻止、未知manifest提示；取消确认不提交报价，关窗口不取消，重开保持业务报价。显式取消核对真实归还；迟到race probe/切存档不向旧view增加Pawn。窗口保护不证明完整manager跨存档ownership安全。
3. **市场双方**：选择单位→价格→发布确认→目录/我的→对方购买确认→实际Pawn与支付核对；缺种族/unknown manifest、重复购买/过期条目/未收到完成消息、发布失败与错误日志。下架核对正确存档归还。OC拦截与原Tradeable规则不变。
4. **租赁双方**：仅colonist可发布；租金/天数须正整数，押金可0、负值/非数字/超int禁止；发布→对方租用→我租用/剩余天数→主动归还/到期/丢失结算，逐项核对真实Pawn、押金/支付/归还。不要把请求回调当成功。所有租期/结算按旧业务规则，本批未重写。
5. **维护清理**：先确认危险操作菜单可达和警告完整。该功能不会归还Pawn，除非明确只在可丢弃测试数据中验证，否则不用真实单位执行。
6. **设置/生命周期**：通知与debug切换、关闭父/子设置窗及重启验证原保存行为；主窗关闭不取消已提交业务，重新打开/模块停用/返回菜单/切档无旧session/source或Pawn预览残留；Game/map变化要求重选物理单位。第三方贡献仍可达、主题热应用正常。
7. **旧1.9组合**：同一人才包走原Draw/adapter，启动/三flow/设置分别待验证。离线类型检查不等于旧游戏通过。
