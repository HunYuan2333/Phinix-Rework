# B10 商店双栏 UX 验收（待测）

候选 B10 Host + Example 1.0.16；重启游戏。非 GUI 测试不等于以下游戏通过。包含此前修复；不要求额外中途 B8 独立验收。

1. 商店主 tab 和独立窗口：宽窗左搜索/筛选/目录，右所选插件/操作/详情。右上操作不被长简介埋藏，两栏文字与控件没有溢出、重叠或异常空白。
2. 目录滚动到中部选插件，再选另一个：左栏位置保留、右栏回顶部；右栏滚动不带走左栏。刷新和搜索仍显示真实数据。
3. 缩小内容宽度：出现“插件 / 详情与操作”；选插件进入详情，返回插件后可继续浏览。恢复宽窗还原双栏；不同 UI scale 与长翻译均可达。
4. 版本切换更新实际版本/状态；安装、更新、启用/禁用、卸载确认、依赖摘要及失效保护按 B9 原业务清单继续验收。回调不等于安装成功。
5. 管理/本地主题包/DevMode 导入/访问线路与第三方贡献仍可达，未迁移窗口继续使用原入口。
6. Example：左侧字段/列表、右侧 feed/引用跳转/计数操作、底部 composer、确认；窄窗切换后文本草稿保留，关闭/stop 后不执行过期操作。
7. 与库存提取、日计划、恢复及聊天 IME/右键无错误日志合批；此前未测事项继续待测。

记录包 SHA、分辨率/UI scale、实际步骤、日志和截图。时间戳位置选项是后续待办，本候选未包含。
