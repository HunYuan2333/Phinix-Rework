# Local Plugin Quickstart

> **中文版**：[本地插件快速入门.md](./本地插件快速入门.md)

Local plugin development does not require GitHub, tokens, Releases, or Index approval. Prepare public Host DLLs once, then compile only your plugin. The sample repository is `HunYuan2333/Phinix-Example-Plugin`, using `ClientExtensionModule.Compose` in `example/ExampleExtension.cs`.

## 1. Prepare References

Reference `Common/Assemblies` from an installed Host, or `Utils.dll` and `ClientExtensionAbstractions.dll` from a built client. Game references are compile-only and never bundled into the plugin ZIP.

When building `ManagedPackageTool` from Host source, keep pinned submodule gitlinks:

```sh
git submodule update --init --recursive
dotnet build Extensions/PluginStore/Tools/ManagedPackageTool/ManagedPackageTool.csproj -c Release -m:1
```

Never run `git submodule update --remote`, and do not introduce an extra Phinix NuGet SDK channel.

## 2. Configure Independent Identity

Copy Example to an independent directory and update `AssemblyName`, `PluginPackageId`, `PluginDisplayName` in `Example.csproj`, along with namespaces, `[PhinixExtension]`, `ExtensionId`, and settings key prefixes. Do not hand-edit `manifest.json`; it is generated by the packager.

Declare compatibility, plugin dependencies, and external mods in `example/package-config.json`:

```json
{
  "compatibility": {
    "rimWorldVersions": ["1.6"],
    "phinixRange": ">=0.9.7 <1.0.0",
    "abstractionsRange": ">=2.0.0 <3.0.0"
  },
  "dependencies": [],
  "externalMods": []
}
```

## 3. Build, Package, and Offline Preflight

Run inside the Example directory:

```sh
python3 pack.py \
  --phinix-root /absolute/path/to/Phinix-Rework \
  --host-assemblies /absolute/path/to/phinix-rework/Common/Assemblies \
  --game-references /absolute/path/to/RimWorld/Managed \
  --output /absolute/path/to/my-plugin-build-1.zip
```

Or invoke `ManagedPackageTool.dll` directly:

```sh
dotnet /path/ManagedPackageTool.dll \
  --assembly /path/My.Plugin.dll --package-id author.plugin \
  --name "My Plugin" --version 1.0.0 --config /path/package-config.json \
  --output /path/build-1.zip
dotnet /path/ManagedPackageTool.dll --validate /path/build-1.zip
```

`--validate` runs offline without installing or executing DLLs, printing package ID, version, digests, modules, dependencies, and compatibility ranges (pass repeatable `--host-assembly` paths to check CLR references).

## 4. Sideloading, Iteration & Diagnostics

1. Enable RimWorld developer mode, open Store → **dev: Install local plugin ZIP** (in the overflow menu on narrow windows).
2. Enter an absolute ZIP path or browse a directory, review package ID, version, and SHA-256, then confirm and restart.
3. In Plugin management, verify `Local dev` provenance, startup states, and digests. Use **Copy details** to export diagnostics (no logs, paths, credentials, or save data are copied).
4. Same-ID, same-version builds with a different ZIP digest create a new local revision; duplicate digests, downgrades, and overwriting another source's package ID are rejected. Existing local packages remain manageable even after developer mode is disabled.
5. Uninstall from Store or Plugin management → Plugin packages; changes take effect on restart.

Before downgrading to a schema-1-only Host, uninstall local packages with the newer Host and restart first. See [Store-Management-Synchronization.md](branch-local/dev/plugin-store/Store-Management-Synchronization.md).

## 5. Theme, Task & Action APIs

- **Theme & Widgets**: Obtain `IClientTheme` / `IClientThemeRegistry` from Host (`RegisterModule(this)`, `RegisterColor(...)`, `Commit()`, `Dispose()` on shutdown). Use `theme.Capture()` with `ClientWidgets` (`Label`, `LabelEllipses`, `Button`, `TextField`, `Border`, `Surface`, `RadioButton`, `RadioOption`) inside `ClientGuiScope`.
- **Main-thread Tasks**: Use `IClientTaskService.ForModule(this)` in `Activate` (`Submit`, observable handle, `Shutdown` disposes scope; see [Client-Task-Api-Implementation.md](branch-local/dev/Client-Task-Api-Implementation.md)).
- **Typed Extension Points**: Use `IClientExtensionPointService.ForModule(this)` (`DefineActions<TContext>`, `ContributeActions<TContext>`, `Collect`, `TryExecute`; see [Plugin-Api-Integration-Standard.md](branch-local/dev/Plugin-Api-Integration-Standard.md)).
