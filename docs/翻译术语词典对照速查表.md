# Phinix Rework 翻译术语词典对照速查表

> 适用范围：`Client/Languages/` 与 `Extensions/PluginStore/Package/Languages/` 下的中（`ChineseSimplified (简体中文)`）/ 英（`English`）界面翻译。  
> 原则：面向普通用户，使用常规软件用语，避免内部工程术语（如 `intent`、`payload`、`codec`、`managed inventory`、`ledger` 等）与冗长的防御性说明句。
