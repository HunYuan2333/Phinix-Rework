# 验证、恢复与兼容

验收、排障、升级或有状态业务时读。已有准确验收记录不重复要求同一范围验证；新宿主、新路径或扩大范围仍需对应证据。

区分：编译证明语法和所用引用可解析；自动化测试证明所覆盖行为；ZIP/CLR 预检证明静态结构和输入引用一致；云端构建证明该固定源码/引用流程；游戏验收证明实机 UI、加载及对应运行场景。任何一层都不能代替其他层。源码修复也不证明商店发行了修复包。

## 游戏检查（未执行时明确待验收）

简单 Tab：独立身份安装，模式开关与窄窗口入口，确认 ID/版本/摘要，重启后发现和激活，设置/翻译，构建修订后实际加载新摘要，启停/卸载与两处管理同步，取消卸载保持停用，下一启动与当前状态可理解。

有状态/联机：至少覆盖五轮切档/回主菜单、断线/重连与退出，无重复订阅或旧世界对象；过期主线程/确认回调无副作用，缺依赖与只读状态明确拒绝。验证匹配/重复/过期回执、确定未发送、明确拒绝、已发送结果未知、codec/Def 缺失及整批失败、幂等重试、存档/日志冲突。先用独立测试存档/副本和可恢复数据，不通过删除持久化记录“修复”。

安装恢复：未提交中断保留旧包；提交后中断完成新包，具体沿用目标宿主事务决定。模式关闭时未提交意图取消、已提交不撤销；重复确认不重复执行。损坏 ZIP、依赖缺失、程序集/模块冲突给准确原因，不留下半安装。进程中断实验应在明确授权的测试环境安排。

## 恢复约束

物品权威回执、普通状态快照和 UI 乐观预览分别处理。未知结果持久保存并与对应服务核对，不能根据超时、排队成功或空历史擅自返还。缺 codec/Mod 不静默过滤；整批交付拒绝时保留原始 payload。库存日志/旧快照保护按当前公开接口交玩家确认，禁止自动重放奖励或手改记录。

Legacy 协议限制由 adapter 收敛；不改变主体确认标准。普通交易旧服务器无法提供新 durable ack 的恢复范围仅当前进程；红包 interrupted relay history 自动核对未实现；人才贸易内存态未结算事务无法自动崩溃恢复。核对目标版本文档及实现，不把历史限制或未经发行修复泛化。

排障先收“复制摘要”中的包/宿主/抽象版本、来源、已安装与当前摘要、发现/激活、依赖及原因码，再定向读取错误。需要更多信息时请用户只提供去除凭据、路径/玩家/存档内容的相关片段。发现宿主能力不足或源码/文档矛盾，记录准确接口与待办，不顺手改宿主业务代码。
