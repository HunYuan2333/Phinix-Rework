# Public client API quick reference

Verified against actual local source; this does not mean working-tree changes are on main. Paths are relative to Host. The default namespace is `PhinixClient.Framework` unless noted. Check declarations for return types and full parameter lists; do not infer overloads from names.

Assembly keys: A = `ClientExtensionAbstractions.dll`, P = `ClientPresentation.Contracts.dll`, U = `Utils.dll`. A still contains Unity/Verse boundaries; the entire SDK is not engine-free. Use presentation, registration, localization and theme mutation on the game main thread. Background work processes game-independent data only.

## Missing or non-public entry points

Do not use `Compose(ContainerBuilder, IClientExtensionContext)`, `IClientApiDirectory.TryResolveApi/GetRequiredApi/ResolveApis`, `IClientTaskScope.Run`, `IClientLocalizer.Translate` or `IClientPresentationRegionContext`. Their actual counterparts are Compose, Capture/TryGet, Submit, Text/Format and IClientPresentationDrawContext as listed above.

`ManagedStorePlanner`, `UiTheme` and `ClientThemePackageService` are internal implementations, not third-party dependencies. At the native boundary, `ClientColorValues.ToUnityColor(ClientRgba)` converts theme values; the extension is in A's `Game/ClientColorValues.cs`.
