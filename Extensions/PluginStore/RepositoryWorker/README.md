# Gateway source moved

[中文](README.zh-CN.md).

The maintained Cloudflare gateway is now [Phinix-Plugin-Gateway](https://github.com/HunYuan2333/Phinix-Plugin-Gateway). Development, tests and deployments run from that independent checkout; do not deploy from this retired location. Main Phinix ships only the client store DLL and languages.

See the new repository's [deployment guide](https://github.com/HunYuan2333/Phinix-Plugin-Gateway/blob/main/DEPLOYMENT.md). Existing Worker/domain/source identities and player data are retained. Remaining ignored dependency/runtime caches here are not maintained source and are excluded from the server Docker context.
